# ✈️ MusaFly - Your Trusted Travel Partner

Welcome to the official frontend repository for **MusaFly**. This is a modern, responsive, and beautiful web application built with **Next.js**, **Tailwind CSS**, and **Framer Motion**. It serves as the primary portal for our users to explore and book Tours, Flights, Visas, and Umrah packages.

## 🚀 Technologies Used
* **Framework:** Next.js (App Router)
* **Styling:** Tailwind CSS
* **Animations:** Framer Motion
* **Language:** TypeScript
* **Deployment:** Vercel

## 📦 Getting Started

First, install the dependencies:

```bash
npm install
# or
yarn install
```

Run the development server:

```bash
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📂 Project Structure
- `/app`: Contains all pages, layouts, and global styles (Next.js App Router).
- `/components`: Reusable UI components used throughout the application.
- `/sections`: Major page sections (Hero, SearchCard, Offers, etc.).
- `/constants`: Global configurations and dummy data used before API integration.
- `/public`: Static assets like images and icons.
